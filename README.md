# Ganesh Chaturthi Invitation

A scroll-driven, single-page invitation for Ganesh Chaturthi celebration. Built with HTML, CSS, and JavaScript featuring smooth scroll choreography, animations, and interactive elements.

**🌐 [Live Website](https://ashishkoli14.github.io/Ganesh-Invitation/)**

## What's Inside

- Hero section with video background
- Animated scroll-based invitation reveal with garlands, bells, and oil lamps
- Event details card with countdown timer
- Google Maps integration for venue location
- WhatsApp share button with pre-filled message
- Interactive mushak (mouse character) with directions button
- Falling petals animation
- Responsive design with accessibility features

## How It's Made

Built entirely with vanilla HTML, CSS, and JavaScript (no frameworks). The page uses:

- **HTML** — Semantic markup with Open Graph tags for social media preview
- **CSS** — Keyframe animations, gradients, and reduced-motion accessibility support
- **JavaScript** — Scroll-linked choreography that animates elements based on viewport position

All styling and scripts are embedded in a single `index.html` file for simplicity and portability.

## Run Locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`
